# Eon

> Eon is a next-generation cloud backup platform that turns cloud backups into live, searchable, strategic assets across AWS, Google Cloud, and Azure. It offers agentless backup, backup posture management, ransomware protection, global search over backups, live/granular restore, and a zero-ETL data-lake tier for analytics and AI. The REST API (OpenAPI 3.0) covers accounts, resources, vaults, snapshots, backup policies, restores, jobs, IAM, billing, and multi-party action approvals.
